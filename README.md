## Buyer Lead Intake 
 A small app to capture, list, and manage buyer leads with sane validation, search/filter, and CSV import/export.

## Installation

1. Clone the repo:
   ```bash
   git clone https://github.com/username/task-manager.git
   cd task-manager

2. Install dependencies:
   ```bash
   npm install
3. Set up environment variables:

- Copy .env.example to .env

-   Add your own values


4. Run the development Server:

   ```bash
   npm run dev
   
## Tech Stack
- Next.js

- User authentication (JWT + NextAuth)
